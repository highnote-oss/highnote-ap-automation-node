# highnote-ap-automation-node

A reference application demonstrating the **AP invoice automation** workflow on the [Highnote](https://highnote.com) platform, built with the [`@highnote-oss/nodejs-sdk`](https://github.com/highnote-oss/nodejs-sdk).

**Stack:** Fastify 5 + React 19 + SQLite (Drizzle ORM) + Highnote Node SDK.

> Detailed setup, architecture, and deployment instructions will be added as the demo lands. For now this is a skeleton — see the design spec in the SDK repo.
